### Использование {#usage}
***Установка:*** Убедитесь, что приложение для watchOS установлено, желательно до первого запуска приложения для iOS. В зависимости от конфигурации оно либо устанавливается автоматически, либо его нужно установить через приложение `Watch` на телефоне.
- @TypeOneCallum сделал отличное [видео по настройке](https://youtu.be/LLTnRuR9p-0?si=7pR8ZvmEVUktW4ZB) (спасибо!). С ним первичная настройка проходит намного проще.
- Для работы приложения нужны iOS 17.5 и watchOS 10.5.
- TestFlight: [https://testflight.apple.com/join/HwgkwcGz](https://testflight.apple.com/join/HwgkwcGz)
- Настройки выполняются в приложении для iOS, а затем передаются в приложение для watchOS. Это работает только если версия для watchOS установлена на часах.
- ***Настройка соединения между приложениями:*** Чтобы все заработало, сначала нужно пригласить самого себя в качестве собственного подписчика. *Данные входа LibreView не подойдут.* В приложении LibreLink / Libre 3 откройте раздел Share / Connected Apps, где есть пункт подключения или управления LibreLinkUp. Нажмите `Add Connection` и укажите адрес электронной почты, который хотите использовать для учетной записи подписчика. На этот адрес будет отправлено приглашение. Адрес может совпадать с тем, который используется для LibreView. Затем установите [приложение LibreLinkUp](https://apps.apple.com/us/app/librelinkup/id1234323923) на телефон и выполните инструкции, используя приглашенный адрес. Может помочь и эта [пошаговая инструкция](https://www.librelinkup.com/articles/getting-started). Убедитесь, что в LibreLinkUp вы видите собственный график уровня глюкозы. После этого откройте FLwatch и введите данные учетной записи подписчика, как описано ниже. Сейчас FLwatch поддерживает только одного отслеживаемого пациента на одну учетную запись подписчика.
- После этого приложение LibreLinkUp можно закрыть или удалить, но позднее оно может понадобиться, чтобы принять новые условия использования, политику конфиденциальности или просто проверить, что учетная запись и соединение по-прежнему работают.
- Чтобы подключиться к учетной записи LibreLinkUp, введите свои данные в FLwatch на вкладке `Connect`. Если приложение для watchOS установлено, данные будут переданы на часы. При необходимости можно повторно передать их, снова нажав кнопку `Connect`.
- Получение и отображение данных может занять до минуты.
- Чтобы использовать расчет инсулина, нажмите на метку IOB на главном экране. Сейчас поддерживаются следующие типы инсулина: быстродействующий (Novolog, Novorapid, ...) и ультрабыстродействующий (Fiasp, Lyumjev, ...). При необходимости можно добавить и другие типы. *Просто дайте знать.*
  - Приложение использует экспоненциальную модель из LoopKit. У модели три параметра: `actionDuration`, `peakActivityTime` и `delay`. Для быстродействующего инсулина это 360, 75 и 10 минут, для ультрабыстродействующего — 360, 55 и 10 минут.
- Есть настройка, позволяющая держать график глюкозы на экране часов в течение часа: на часах или в приложении `Watch` на телефоне откройте Настройки -> Основные -> Возврат к часам, прокрутите вниз, нажмите `FLwatch` и выберите `Через 1 час`. Так FLwatch будет оставаться на переднем плане час и получать разумное количество обновлений, например примерно раз в минуту.
- Самый простой способ запускать приложение на телефоне или часах — разместить виджет или осложнение на главном экране, экране блокировки, циферблате или в другом удобном месте и нажимать на него.
- Чтобы открывать приложение без помощи рук через Siri, можно создать на телефоне команду, например с названием `график глюкозы` или `сахар крови`. Эта команда просто открывает FLwatch. Выберите для нее опцию `показывать на Apple Watch`. После этого достаточно активировать Siri и произнести название команды, и откроется FLwatch с графиком.
То же самое работает и на телефоне.

### Возможности {#features}
* График уровня глюкозы на телефоне и часах
* Интерактивный график на телефоне для просмотра отдельных значений по нажатию
* Режим постоянно включенного экрана на телефоне
* Поддержка быстродействующих и ультрабыстродействующих болюсных инсулинов
* Расчет insulin on board (IOB)
* График IOB
* График активности инсулина
* Виджеты iOS и виджеты экрана блокировки с графиком и без него
* Live Activities
* Виджет для режима ожидания
* Виджеты / осложнения watchOS
* Поддержка CarPlay через виджеты и Live Activities
